# Task 2: Executive sales and profit dashboard (Power BI)

## Objective

Build an interactive Power BI dashboard that lets an executive see sales and profit performance at a glance and filter it by date and region.

## What is in this folder

| Path | Contents |
|---|---|
| `powerbi/` | The Power BI file (`.pbix`) |
| `exports/` | PDF export of the dashboard |

## What the dashboard includes

- A star schema data model, with a fact table linked to dimension tables
- DAX measures for the key sales and profit figures
- KPI cards for the headline numbers
- Date and region slicers that filter every visual
- Treemaps showing where sales and profit are concentrated

# Datheon Data Analytics & Power BI Internship

This repository holds the project work I completed for the Datheon Data Analytics & Power BI Internship. It covers three tasks: exploratory data analysis in Python, an executive sales dashboard in Power BI, and a customer churn analysis that combines Power BI with statistical testing in Python.

## Projects

| Task | Project | Main tools | Folder |
|---|---|---|---|
| 1 | Superstore retail sales: exploratory data analysis | Python, pandas, seaborn, Jupyter | [Task1_Superstore_EDA](Task1_Superstore_EDA) |
| 2 | Executive sales and profit dashboard | Power BI, DAX | [Task2_PowerBI_Sales_Dashboard](Task2_PowerBI_Sales_Dashboard) |
| 3 | Customer cohort and churn analytics | Power BI, Power Query, DAX, Python | [Task3_Customer_Churn_Analytics](Task3_Customer_Churn_Analytics) |

Each folder has its own README with the objective, method, results and instructions for opening the files.

## Tools used

Power BI Desktop (Power Query and DAX), Python 3 (pandas, NumPy, SciPy, statsmodels, seaborn, Matplotlib) and Jupyter Notebook.

## Notes

The datasets are public sample datasets used for learning. No private or customer data is included.
